## Completion and adaptation

- Mock score capture and analytics review are complete. Learner cold reattempts/repairs remain pending. No XP is awarded for Codex's logging work.
- Preserve completed task and XP history. Retire superseded pending tasks without counting them as completed. Future tests always use the next **unused** paper.
- A fresh question or set means unseen and attempted before hints. Seen-question redos test retrieval; fresh transfer tests learning.
- Redo failures after about 48 hours and once in the following week's mixed work. Codex attaches these to existing cards; the learner has no logging task.
- If cold attempt and targeted practice show missing knowledge, watch only the relevant lesson/segment, then apply it to two fresh questions. A slow correct route triggers route comparison and practice first.
- On fresh QA batches, aim first for >=80% accuracy; then reduce median time on comparable correct questions. On DILR, require two consecutive fresh fully correct sets in the repaired structure before calling the model reliable. These are training gates, not percentile guarantees.
- Assess the sectional goal using each paper's own percentile mapper. Seek >90 in three of the latest four full mocks with no recent result below 85 as a **working stability signal**; this does not guarantee CAT performance. If mock volume is insufficient, call readiness unproven.
- Once all section floors improve, retain both QA/DILR practice and allocate additional work to the largest expected overall-score gain. Do not stop at 90.
- If prior review and fresh transfer are unfinished, replace the next test with that repair cycle. Missed dates move the active sequence forward without stacking tests or awarding false completion.
- Full-mock and sectional timings measure execution. Untimed diagnosis is allowed before applying speed pressure. There is no arbitrary daily time ceiling.
- Six full mocks are provisionally scheduled through 23 November. Dates through 28 November preserve the existing plan horizon; verify exam logistics/date from official instructions before tapering.
